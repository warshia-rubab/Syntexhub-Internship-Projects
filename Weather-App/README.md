# 🌤️ Weather App

A professional weather forecasting application built with React during my internship at Syntexhub.

## 🚀 Features

- Real-time weather data from OpenWeatherMap API
- 5-day weather forecast
- Dark/Light theme toggle
- Search history
- Popular cities quick access
- Weather analytics with charts
- Responsive design

## 🛠️ Tech Stack

- React 18
- Vite
- CSS Modules
- Axios
- React Icons
